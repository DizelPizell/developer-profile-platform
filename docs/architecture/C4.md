# C4 Model

## Level 1 - System Context

### People
- Developer
- Recruiter / Employer
- Technical Reviewer

### System
Developer Professional Profile Platform

### External systems
- GitHub
- S3-compatible Object Storage

## Level 2 - Containers

### Web Application
Next.js + TypeScript. Public profiles, dashboard, project pages, technical workspace and analytics UI.

### Backend API
FastAPI + Python. Authentication, business rules, profiles, projects, GitHub, analytics and files.

### PostgreSQL
Users, profiles, projects, normalized GitHub data, analytics and application state.

### Object Storage
Avatars, screenshots and other uploads.

### Optional Background Worker
GitHub synchronization and future asynchronous jobs.

## Level 3 - Backend Components

```text
FastAPI
 |
 +-- Auth
 +-- Profile
 +-- Projects
 +-- GitHub
 +-- Analytics
 +-- Files
 +-- Users
 |
 +-- API Layer
 +-- Application Layer
 +-- Domain Layer
 +-- Persistence Layer
 +-- Infrastructure Layer
```

Exact package layout can evolve, but domain boundaries must remain clear.
