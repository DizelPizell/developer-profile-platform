Правила
Данные
Экран: GET /analytics/profile?days=N. Раскрытый проект: GET /analytics/projects/{id}?days=N, заново при смене периода. Шапка — useAccount (GET /profile), оттуда же статус профиля для D.
Воронка
Профиль = profile_views, Проекты = project_views, Демо и GitHub = demo_clicks + github_clicks (с разбивкой), Контакты = contact_clicks. Без процентов, без «конверсии», без цвета-оценки (ADR-0029, CLAUDE.md: никаких рейтингов).
Проекты
Все свои, в порядке API (= «Мои проекты»), нули — серым. Статус — как в «Мои проекты»: Опубликован, Скрыт, Черновик, В архиве.
График
Одна серия — просмотры проекта; клики — числами под графиком и в таблице (две шкалы на одном графике не рисуем). Цвет — accent на фоне bg (на panel контраст ниже 3:1), наведённый столбик — label. Без легенды: подпись над графиком называет серию.
Даты
Дни — UTC, как в API; формат ДД.ММ, в подписи периода ДД.ММ.ГГГГ. Без пересчёта в часовой пояс браузера: иначе «сегодня» не совпадёт с днём счётчика.
Период
В состоянии экрана, не в адресе: после обновления — снова 30 дней.
