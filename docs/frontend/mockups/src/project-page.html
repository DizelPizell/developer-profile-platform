FСсылка — только название (подчёркнуто). Отдельного «Открыть проект ›» нет, картинки на карточке нет: в whitelist карточек нет скриншотов (ADR-019). Блок GitHub карточек не меняется и здесь опущен.

Правила
Порядок
Назад к профилю → название → Демо → Скриншоты → Задача, Мой вклад, Результат, Подробнее → Данные GitHub.
Демо
Только если demo_url разбирается и протокол http: или https:. Иначе блока нет, одна строка в лог сервера без значения. Ссылка: новая вкладка, rel="noopener noreferrer nofollow ugc". Без iframe, сервер URL не запрашивает.
Скриншоты
img с width и height, loading="lazy" (кроме превью). Картинка — ссылка на свой url в новой вкладке, «Открыть скриншот N в полном размере». Без лайтбокса. url только вида /media/…, иначе скриншот пропущен.
Тексты
Простой текст, переносы строк сохраняются, без разметки, не шире 70 знаков. null — блока нет.
Источник
Поля автора — «От автора». GitHub — отдельная секция с «Источник: GitHub», тот же компонент и whitelist, что на карточках. github: null — секции нет.
Адрес
Слаг по правилам профиля, id — канонический UUID; заглавные → 308 на строчный адрес. Кривой адрес — 404 без запроса к API.
Ошибки
404 — экран E3. Остальное — «Не удалось загрузить проект» и «Повторить», HTTP 500.
Не показываем
Оценки, счётчики, просмотры, «проверено», статус и видимость проекта.
