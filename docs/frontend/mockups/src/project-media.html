Правила и тексты ошибок
Ссылка на демо
Поле формы: «Сохранить», в PATCH только при изменении. Очищенное — null (пустая строка — ошибка API). Без счётчика, maxLength 2048. Клиент URL не проверяет.
Скриншоты
Сохраняются сразу, как привязка репозитория. Ответ — весь список; форма берёт только его, правки полей остаются.
До запроса
Больше 5 МБ — «Файл больше 5 МБ.» Другой тип — «Подходят JPEG, PNG и WebP.» Решает всё равно сервер, по содержимому.
invalid_image
«Не получилось прочитать картинку. Подходят JPEG, PNG и WebP.»
image_too_large, 413
«Файл больше 5 МБ.» 413 от Nginx — HTML, читается по статусу.
too_many_pixels
«Слишком большое изображение: не больше 40 мегапикселей.»
Подпись 422
«Не больше 200 символов.», «Недопустимые символы.», «Некорректное значение.»
Ссылка 422
invalid_url — «Допустимы только ссылки http и https.», string_too_long — «Не больше 2048 символов.»
409 limit
«Можно добавить не больше 6 скриншотов. Список загружен заново.»
409 order
«Список скриншотов изменился, порядок загружен заново.»
404
Код один для скриншота и проекта: форма перечитывает проект. 200 — «Скриншот не найден. Список загружен заново.», 404 — панель «Проект не найден».
Объявления
Итоги и ошибки — в live region блока (role="status"): «Скриншот добавлен.», «Подпись сохранена.», «Скриншот удалён.», «Порядок изменён.»
