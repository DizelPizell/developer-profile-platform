# Scope v1 — зафиксировано 2026-10-01

> **Статус: в работе.**

V1 — первый рабочий релиз платформы. Разработчик входит через GitHub, заполняет профиль с контактами, создаёт проекты с демо, скриншотами и привязанным репозиторием, публикует их; посетитель открывает страницу проекта, демо, данные GitHub и связывается с разработчиком. Всё работает в продакшне по HTTPS, с бэкапами и мониторингом.

## Что входит

1. **Аутентификация** — вход и выход через GitHub OAuth.
2. **Профиль** — редактирование, публикация, публичная страница.
3. **Контакты** — email, Telegram, LinkedIn, телефон и «другие способы связи».
4. **Проекты** — CRUD, публикация, архивация, видимость.
5. **Витрина** — до 3 избранных проектов с порядком.
6. **Страница проекта** — `/u/{slug}/projects/{id}` с демо, скриншотами и блоком GitHub.
7. **Интеграция с GitHub** — список репозиториев, привязка, импорт, синхронизация.
8. **Инфраструктура** — Docker, CI, Nginx, HTTPS, бэкапы, мониторинг.

Не входит в V1: аналитика (V1.1), рабочее пространство с кодом, опыт/навыки/образование, поиск кандидатов, вакансии, сообщения.
