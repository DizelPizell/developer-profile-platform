# ADR-0004: Роль и вклад — поля проекта, а не отдельная сущность

- **Статус:** принято 2026-10-01
- **Релиз:** v1
- **Связано:** [0015](0015-project-model.md) — полная модель проекта

## Контекст

Исходная концептуальная модель содержала отдельную сущность `PROJECT_CONTRIBUTION`. В V1 нужно описать только роль и вклад текущего разработчика в проекте. Несколько контрибьюторов на одном проекте — не требование V1.

## Решение

Хранить `projects.role` и `projects.contribution` напрямую на сущности Project.

Не вычислять процент вклада автоматически из коммитов. Не создавать искусственные оценки навыков из активности на GitHub.

## Отвергнуто

- **Отдельная сущность `PROJECT_CONTRIBUTION`** — моделирует будущую многопользовательскую функциональность до того, как продукт её требует.

## Последствия

Модель V1 проще. Если потребуется многопользовательская модель, она вводится отдельным решением.
