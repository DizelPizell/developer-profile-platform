# ADR-0007: GitHub — источник технических данных о репозитории, разработчик — источник контекста

- **Статус:** принято 2026-10-01
- **Релиз:** v1
- **Связано:** [0010](0010-github-evidence-model.md), [0019](0019-public-github-on-cards.md)

## Контекст

Профиль объединяет технические факты (что сделано) и контекст от разработчика (какую роль он играл, зачем). Нельзя смешивать эти два источника — иначе невозможно отличить факт от самооценки.

## Решение

GitHub — источник технических данных о репозитории (метаданные, языки, README, дерево файлов, контрибьюторы, коммиты).

Разработчик — источник контекста: роль, личный вклад, бизнес-проблема, результаты, скриншоты, demo URL.

UI должен различать эти источники.

Не создавать автоматических оценок навыков или процентов вклада из активности на GitHub.

## Последствия

Платформа избегает изобретения технических оценок. Данные GitHub и текст разработчика не смешиваются в одной области страницы.
