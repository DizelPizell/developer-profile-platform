# ADR-0005: Жизненный цикл и видимость проекта разделены в отдельные концепции

- **Статус:** принято 2026-10-01; уточнено [0015](0015-project-model.md)
- **Релиз:** v1
- **Связано:** [0015](0015-project-model.md) — допустимые комбинации и переходы

## Контекст

Состояние публикации и публичная доступность отвечают на разные вопросы. Смешение их в одном поле затрудняет разграничение «черновик/архив» и «показывать/скрывать».

## Решение

Жизненный цикл проекта (`projects.status`): `DRAFT`, `PUBLISHED`, `ARCHIVED`.

Видимость проекта (`projects.visibility`): `PUBLIC`, `PRIVATE`.

Доменный слой отвергает недопустимые комбинации. База данных дублирует правило CHECK (`ck_projects_state`).

Допустимые пары (детализировано в [0015](0015-project-model.md)):
- `DRAFT` + `PRIVATE`
- `PUBLISHED` + `PUBLIC`
- `PUBLISHED` + `PRIVATE`
- `ARCHIVED` + `PRIVATE`

Жизненный цикл профиля проще: `PRIVATE` → `PUBLISHED`. Снятие с публикации возвращает в `PRIVATE`; отдельного состояния `UNPUBLISHED` нет.

## Последствия

Модель явно разделяет состояние подготовки от политики экспозиции. Переходы реализованы идемпотентными `POST`-действиями.
