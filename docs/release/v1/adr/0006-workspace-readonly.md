# ADR-0006: Рабочее пространство проекта — только для чтения, без выполнения кода

- **Статус:** принято 2026-10-01; перенесено после V1 2026-11-04
- **Релиз:** после v1
- **Связано:** [0018](0018-github-sync-v1.md) — дерево файлов и README отложены

## Контекст

Платформа должна давать возможность изучить технические доказательства проекта. Выполнение произвольного кода репозиториев в рамках платформы требует серьёзных вложений в безопасность и инфраструктуру — песочница, изоляция, лимиты ресурсов, сетевые ограничения.

Примечание 2026-11-04: рабочее пространство перенесено после V1. Решение ниже остаётся в силе для момента, когда оно вернётся.

## Решение

Рабочее пространство — только для чтения: дерево файлов, просмотр кода, README, архитектура, тесты, история Git, документация.

Платформа не выполняет произвольный код проекта.

## Отвергнуто

- **Управляемая песочница** — рассмотреть отдельно, когда появится конкретное требование.

## Последствия

V1 безопаснее и проще. Технический опыт просмотра сохраняется. При возврате рабочего пространства потребуются миграция и новый код.
