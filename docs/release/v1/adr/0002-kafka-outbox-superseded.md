# ADR-0002: Kafka и Outbox использованы для асинхронной синхронизации с GitHub

- **Статус:** заменено [0008](0008-no-kafka-v1.md) 2026-10-03
- **Релиз:** v1

> Это решение было принято и затем отменено. Текст сохранён как исторический документ. Актуальное решение — [0008](0008-no-kafka-v1.md).

## Контекст

Синхронизация GitHub не должна блокировать HTTP-запрос. Прямая публикация в Kafka после записи в PostgreSQL создаёт проблему dual-write.

## Решение

Использовать PostgreSQL для хранения джобов, Outbox-таблицу для надёжной публикации событий, Kafka как транспорт, GitHub Sync Worker как потребитель.

## Последствия

Надёжная доставка, асинхронная обработка, но: Kafka — ещё один компонент, Outbox-relay — ещё один, нужно обрабатывать дубликаты.

## Почему заменено

Операционная сложность Kafka диспропорциональна требованиям V1. PostgreSQL уже является надёжным источником истины и может хранить джобы напрямую. Решение принято в [0008](0008-no-kafka-v1.md).
