# ADR-0003: GitHub OAuth-токен хранится зашифрованным на уровне приложения

- **Статус:** принято 2026-10-01; не применяется в V1 (см. [0016](0016-github-public-data-app-credentials.md))
- **Релиз:** v1
- **Связано:** [0016](0016-github-public-data-app-credentials.md) — в V1 токен пользователя не запрашивается и не хранится

## Контекст

Если платформа будет хранить GitHub OAuth-токен пользователя, то хранение открытым текстом создаёт высокорисковую утечку секретов.

Примечание 2026-10-30: в V1 токен пользователя не хранится — платформа читает только публичные данные с кредами приложения ([0016](0016-github-public-data-app-credentials.md)). Это решение остаётся актуальным на случай, если токен когда-либо появится (например, через GitHub App).

## Решение

Хранить GitHub-токен зашифрованным на уровне приложения. Ключ шифрования — из окружения / secret management.

Токен не должен:
- возвращаться в API-ответах;
- логироваться;
- передаваться на фронтенд;
- попадать в Git.

## Последствия

Нужна инфраструктура шифрования и ротации ключей. В V1 не реализуется.
