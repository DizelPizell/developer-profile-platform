# ADR-006: GitHub as Technical Evidence Source

Status: **Superseded by ADR-007-github-is-source-of-technical-evidence.md** (2026-10-03)

> Note: this decision has been reformalized in `ADR-007-github-is-source-of-technical-evidence.md` (the current ADR-NNN numbering convention — see `docs/adr/README.md`). This document is retained for historical record and is not actively maintained.

GitHub is the source of truth for technical repository evidence. The platform normalizes/cache data locally for performance.

Developer-provided fields describe context such as role and contribution.

The platform must not invent contribution percentages or skill scores.
