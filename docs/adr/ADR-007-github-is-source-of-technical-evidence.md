# ADR-007: GitHub as Technical Evidence Source

## Status

Accepted

## Context

The profile needs both technical facts and developer-provided context.

## Decision

GitHub is the source of technical repository evidence.

The developer is the source of contextual project information.

GitHub-derived information and developer-provided information should be distinguishable in the UI.

## Consequences

The platform avoids inventing technical assessments.

No automatic skill or contribution score is created from repository activity.
