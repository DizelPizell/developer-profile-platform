# ADR-011: Evidence Over Scores

Status: **Accepted**

Do not create a universal developer score, skill score or inferred contribution percentage.

Show project context, contribution, GitHub evidence, demos, architecture, tests and Git history instead.

## Note (2026-10-03)

The GitHub-specific application of this principle is formalized in `ADR-007-github-is-source-of-technical-evidence.md`. This ADR remains active as the general, product-wide principle.
